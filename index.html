Abstract

Moonshine-Base ships with a byte-level decoder vocabulary tuned for English, which fragments Bengali text into long token sequences and destabilizes autoregressive decoding under low-resource fine-tuning. We propose tokenizer transplantation: replacing the model's native decoder vocabulary with BanglaBERT's WordPiece vocabulary, reducing token fertility from 9.16 to 1.30 tokens per word. Direct vocabulary substitution disrupts the decoder's learned embedding space, so we recover performance through a two-stage ScheduleFree AdamW fine-tuning schedule. The resulting 61.5M-parameter model reaches 21.54% WER and 10.79% CER on the Lipi-Ghor-bn-882-SSTT test set, with a real-time factor of 0.0053 on GPU — making it practical for on-device Bengali ASR where Whisper-scale models are not.
